# 特征表索引

先读本文，不要整篇通读 `ai-flavor-patterns.md`。

## 用法

1. 先读 `task-binding.md` 确定当前任务的适用层。
2. 在本文按关键词定位候选条目。
3. 只在确认文本里确实出现了该特征时，才去 `ai-flavor-patterns.md` 读该条详情（含改法与例外）。
4. 同一会话读过的不重复读取。

## 按层定位

### L0 事实与归属

| 编号 | 特征 | 定位关键词 |
|---|---|---|
| 0.1 | 编纂不实内容 | 同事、朋友、某大厂、真实案例、对话、评论 |
| 0.2 | 虚假精确 | 提升、倍的、百分之、成以上、管用 |
| 0.3 | 模糊归因 | 专家认为、行业报告、观察者、有观点认为 |
| 0.4 | 无意义的重要性拔高 | 标志着、见证了、里程碑、关键时刻、历史意义 |
| 0.5 | 过度强调知名度 | 被媒体引用、粉丝、社交媒体、广受关注 |
| 0.6 | 知识截止声明残留 | 截至、根据我最后、基于可用信息、目前资料有限 |

### L4 节奏与体温

| 编号 | 特征 | 定位关键词 |
|---|---|---|
| 4.1 | 通篇无停顿 | 情绪曲线平、无短段、无自我质疑 |
| 4.2 | 段落等厚 | 每段句数接近、功能相同 |
| 4.3 | 段尾一律收束 | 每段末尾补抽象结论 |
| 4.4 | 绝对确定感 | 一定、必然、所有人、毫无疑问、必然如此 |
| 4.5 | 无立场与视角 | 全程中立报道、不敢表态、无第一人称 |
| 4.6 | 数字与细节模糊 | 很多人、近年来、大幅提升（该具体处反而模糊） |
| 4.7 | emoji 滥用 | 段落或标题以 emoji 开头、emoji 替代标点 |
| 4.8 | 粗体滥用 | 大量短语加粗、加粗做装饰 |
| 4.9 | 内联标题垂直列表 | 每条为"粗体标题：解释" |
| 4.10 | 弯引号与标点不一致 | 直引号与弯引号混用、破折号机械使用 |
| 4.11 | 段落开场短句惯性 | 每段都以短判断句开头 |
| 4.12 | 英文标题大写 | 中英混排标题全部实词首字母大写 |

## 输出约束

不要把清单念给用户。修补模式只给成品与 3-5 条改动说明；诊断模式只给 5-10 条最影响读感的问题及修法方向。
